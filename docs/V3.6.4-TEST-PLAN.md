# OHLI Social v3.6.4 — rencana validasi

## Skenario pertemanan

Jalankan `node tools/source-verify.mjs` terlebih dahulu. Setelah APK terpasang dan server aktif, siapkan dua akun khusus uji (jangan gunakan akun utama), lalu isi `OHLI_BASE_URL`, `OHLI_PHONE_A`, `OHLI_PASSWORD_A`, `OHLI_PHONE_B`, dan `OHLI_PASSWORD_B`. Jalankan `node tools/smoke-test.mjs`.

Skenario tambahan pada smoke test v3.6.4 memverifikasi:

1. Akun B mengirim permintaan kepada A menggunakan ID publik `oh_…`.
2. Permintaan berulang tidak menghasilkan relasi ganda.
3. A melihat permintaan masuk lalu menerima.
4. Daftar teman tetap terbaca dari sesi kedua akun B.
5. A menghapus teman dan relasi hilang dari daftar kedua akun.
6. Alur tolak permintaan dan batalkan permintaan terkirim.

Tes ini memodifikasi state pertemanan dan membuat notifikasi uji pada dua akun. Jalankan hanya pada akun disposable.

## Pemeriksaan tambahan manual

- Buka profil akun lain, uji tambah teman, terima/tolak, batalkan, dan hapus.
- Buka Menu OHLI Social → Teman pada HP dan desktop; pastikan tombol tidak terpotong dan daftar dapat digulir.
- Periksa status Online dengan privasi aktivitas diatur menjadi Publik, lalu sembunyikan aktivitas dan pastikan status tidak tampil.
- Uji blokir di kedua arah; permintaan teman harus ditolak dan akun tidak muncul di daftar.

## Batas validasi

Pemeriksaan statis tidak membuktikan runtime server, APK, atau dua perangkat. Build APK melalui GitHub Actions dan pengujian di Android harus dilakukan sebelum mengganti APK yang sedang dipakai. Fitur LIVE multi-kamera 2–4 orang dan Random Live Match belum termasuk implementasi v3.6.4.
