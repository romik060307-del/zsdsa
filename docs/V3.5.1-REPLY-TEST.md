# Uji balas pesan v3.5.1

1. Login akun A dan B pada dua perangkat/browser berbeda.
2. Kirim beberapa pesan bolak-balik.
3. Di HP, geser bubble dari kiri ke kanan. Bar kutipan harus menampilkan pengirim dan cuplikan pesan.
4. Ketik balasan lalu tekan Kirim.
5. Di akun penerima, pastikan bubble berisi kutipan pesan asal dan teks balasan.
6. Ulangi dengan menu tekan lama > Balas.
7. Pastikan geser vertikal untuk scroll tetap bekerja.
8. Ulangi di desktop menggunakan menu konteks/klik kanan > Balas.

Lulus hanya jika balasan terkirim, kutipan terlihat pada kedua akun, dan tidak ada balasan kosong.
