# Checklist pengujian OHLI Social v3.4.0

Dokumen ini membedakan pemeriksaan source yang dapat dilakukan otomatis dari
pengujian runtime yang memerlukan APK, browser, kamera, mikrofon, dan akun nyata.

## Otomatis — telah dijalankan

- [x] `node --check app/src/main/assets/ohli-social.js`
- [x] `node --check tools/source-verify.mjs`
- [x] `node --check tools/smoke-test.mjs`
- [x] `node tools/source-verify.mjs` — 77 pemeriksaan statis lulus.
- [x] ZIP final diperiksa dengan `zip -T`.

Pemeriksaan statis tidak membuktikan bahwa alur media, kamera, komentar, atau
perangkat fisik berjalan di runtime.

## Perlu dilakukan setelah APK berhasil dibuat

- [ ] Android Chrome: unduh video yang diizinkan; verifikasi watermark dan audio.
- [ ] Android Chrome: pastikan unduh ditolak saat pemilik menonaktifkan download.
- [ ] iPhone/Safari: uji format ekspor, audio, penyimpanan file, dan ukuran video.
- [ ] Profil: ganti mode Transparan/Terbatas, muat ulang, dan periksa grid media.
- [ ] Dua akun: balas komentar utama dan balasan, lalu periksa nesting.
- [ ] Dua akun: like/unlike komentar dan pastikan hitungan tidak berlipat.
- [ ] Dua akun: kirim stiker bawaan dan gambar impor; buka dari akun penerima.
- [ ] Perangkat host + penonton: uji izin kamera/mikrofon, pratinjau, flip kamera,
      komentar, like, follow, share, keluar, serta kualitas koneksi LIVE.
- [ ] Chat mobile: buka percakapan lama dan pastikan langsung menuju pesan terbaru.
- [ ] Chat mobile: gulir ke atas, terima pesan baru, dan pastikan tidak melompat.
- [ ] Video: tekan lama pada video; pastikan menu Copy bawaan tidak muncul.
- [ ] Story: tahan di tengah video lalu lepaskan; pastikan melanjutkan pada waktu sama.
- [ ] Tema: ganti Terang/Malam, pindah antarhalaman, muat ulang, dan login kembali.
- [ ] Desktop: ulangi alur utama pada ukuran layar lebar.

## Infrastruktur LIVE

LIVE saat ini memakai WebRTC peer-to-peer dan membatasi enam penonton langsung.
Komentar menggunakan polling berkala. Untuk siaran publik berskala besar,
siapkan TURN dan SFU/relay; layanan itu belum disediakan oleh source ini.
